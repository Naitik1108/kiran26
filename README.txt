# KIRAN THE FEST — 2026

A cinematic, responsive single-page festival website based on the supplied Kiran logo.

## Run
Open `index.html` in a browser, or use any static hosting service.

## Background video
The site is already wired for a local background video:
`assets/hero.mp4`

Add your own MP4 at that exact path. Until then, the site automatically falls back to its black/red animated visual treatment.

## Content placeholders
The following are intentionally marked "COMING SOON":
- About
- Events
- Leaderboard
- Archive
- Core Team
- Sponsors
- Contact

Replace the placeholder text/cards with the actual 2026 details when available.

## Design
Black / Kiran red / white, cinematic typography, full-screen menu, animated cards, responsive mobile layout, cursor glow, section reveal animations.
